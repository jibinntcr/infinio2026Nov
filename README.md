# Infinio Technology Solutions — 3D Spatial Web & MongoDB Platform

An interactive 3D WebGL and editorial web platform for **Infinio Technology Solutions** (Thrissur · Kochi · Dubai), built with **Next.js (App Router)**, **React Three Fiber / Three.js**, **Lenis Smooth Scroll**, and **MongoDB / Mongoose**.

## Quick Start

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
